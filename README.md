# 유리알의 밤 · Glass Night Tetris

> 가을이 다 저문 어느 밤, 하늘에서 유리알이 떨어진다.

짙어가는 가을 밤하늘을 배경으로, 유리알처럼 맑고 투명한 블록을 쌓는 웹 테트리스입니다.
**의존성 없음 · 빌드 없음 · 외부 요청 없음.** `index.html` 을 더블클릭하면 바로 실행됩니다.

기획 문서: [`docs/PRD.md`](docs/PRD.md)

---

## 실행

```bash
# 1) 그냥 파일을 연다
open index.html            # macOS
xdg-open index.html        # Linux
start index.html           # Windows

# 2) 또는 로컬 서버로 (선택)
python3 -m http.server 8080

```

GitHub Pages 에 그대로 올려도 동작합니다. 빌드 단계가 없습니다.

## 규칙

가이드라인을 따르는 표준 테트리스입니다.

- 10 × 20 필드, 위쪽에 2행의 숨은 스폰 버퍼
- **7-bag** 랜덤 — 일곱 조각이 한 번씩 나온 뒤에야 다음 주머니가 열립니다
- **SRS 회전 + 월킥** (JLSTZ 표 / I 전용 표)
- **홀드** 조각당 1회 · **고스트** · **락 딜레이** 500ms(최대 15회 리셋)
- **T-스핀** 3-코너 판정, **Back-to-Back** ×1.5, **콤보** 50 × 콤보수 × 레벨
- **퍼펙트 클리어** — 바닥을 통째로 비우면 800~2000 × 레벨을 얹어 준다
- 점수: 1줄 100 / 2줄 300 / 3줄 500 / 4줄 800 (× 레벨), 소프트 드롭 1점·하드 드롭 2점 per 칸
- 10줄마다 레벨 +1, 낙하 간격이 일정 비율(초반 ×0.86 → 후반 ×0.80)로 조여 온다

> 화면 문구는 이 세계의 말로 옮겨 두었다. '테트리스'는 **네 줄**,
> 'T-스핀'은 **비틀어 넣었다**, '콤보'는 **연속**, '홀드'는 **품기**.

## 세계관

조각들은 계절이 남기고 간 유리 파편입니다. 한 줄을 온전히 메우면 다시 별빛으로 부서져 흩어집니다.

| 조각 | 이름 | 유래 | 결 |
|---|---|---|---|
| I | 서리결 | 첫서리가 길게 내려앉은 자리 | 가로로 세 줄 |
| O | 달빛알 | 보름달이 물에 비쳐 그대로 굳은 알 | 한가운데 세로 한 줄 |
| T | 자수정 | 밤이 가장 깊을 때만 캐낼 수 있다 | 비스듬히 선 두 줄 |
| S | 이끼결 | 돌 그늘에서 자란 초록 | 왼쪽으로 누운 잎맥 |
| Z | 단풍잎 | 떨어지다 말고 굳어버린 잎 | 오른쪽으로 누운 잎맥 |
| J | 쪽빛 | 해가 완전히 진 직후 하늘에서 가장 짙은 자리 | 깊게 팬 한 줄 |
| L | 감빛 | 서리 맞은 감이 끝까지 품고 있던 온기 | 세 겹으로 겹친 결 |

조각마다 '결'을 달리 새긴 것은 멋 때문만이 아니다. 색만으로 구분하면
색을 잘 구분하지 못하는 사람에게는 **이끼결과 단풍잎이 같은 조각**이 된다.
결은 색 말고 단서를 하나 더 주고, 깎은 유리처럼 보이는 덤이 따라온다.

### 밤이 깊어진다

세계관은 장식이 아니라 시스템입니다. **레벨 진행이 곧 시간의 흐름**이고, 배경 하늘이 실제로 변합니다.

| 시각 | 레벨 | 하늘 |
|---|---|---|
| 해거름 | 1 | 보랏빛 위 서쪽의 붉은 잔광, 별은 거의 없다 |
| 초저녁 | 4 | 남보라로 가라앉고 첫 별이 돋는다 |
| 깊은 밤 | 8 | 짙은 감청, 달이 중천에 오른다 |
| 자정 | 12 | 거의 검정에 가까운 남색, 별이 가장 밝다 |
| 서리 새벽 | 16 | 푸른 기가 도는 검정, 달이 기울어 내려간다 |

레벨 사이는 색을 보간해 이어 붙이므로 하늘이 툭 끊기지 않고 서서히 물듭니다.
이웃한 시각 사이의 색 거리는 최소 78(측정값)이라 다섯 시각이 각각 또렷합니다.
제목 옆의 가느다란 게이지는 **밤이 얼마나 깊었는지**를 보여 줍니다 — 눈금 다섯 개가 곧 다섯 시각.

**얼마나 오래 버텼는지를 점수판이 아니라 하늘을 보고 알 수 있습니다.**

### 유리알은 어떻게 만들었나

단색 사각형에 알파값만 낮추면 '반투명한 색종이'가 됩니다. 유리알로 보이려면 세 가지가 필요합니다.

1. **캔버스 2겹** — 뒤쪽에 밤하늘 캔버스, 앞쪽에 **배경이 투명한** 게임 캔버스.
   블록 너머로 별과 달이 실제로 비칩니다. (블록 중앙 픽셀 알파 ≈ 87/255)
2. **한 칸당 여섯 층** — 뒤쪽 발광 · 두께 그라데이션 · 안쪽 굴절 테두리 ·
   상단 하이라이트 · 대각 반사 스트릭 · 바깥 윤곽선, 그리고 조각별 '결'. (`js/glass.js`)
3. **알마다 조금씩 다르게** — 빛이 닿는 자리를 세 갈래로 나눠 구워, 쌓였을 때
   타일 무늬처럼 반복되지 않게 했습니다.

성능을 위해 모양이 변하지 않는 알은 오프스크린 캔버스에 한 번 구워 재사용합니다.
정작 프레임을 잡아먹던 것은 파티클이 아니라 `backdrop-filter` 였고
(실측 21.4ms → 16.7ms), 상시 표시되는 패널에서 걷어내 **60fps**를 확보했습니다.

## 테스트

```bash
node tests/engine.test.js         # 규칙 검증 37항목 (의존성 없음)
node tests/acceptance.js          # PRD 수용 기준 AC-1~13
node tests/acceptance.js ./shots  # 스크린샷까지 남기며 실행
node tests/perf.js                # 프레임·입력·난이도·레이아웃 실측
node tests/fuzz.js                # 적대적 테스트 12종
```

`tests/engine.test.js` 는 `js/engine.js` 가 DOM에 의존하지 않으므로 Node 에서 그대로 돌아갑니다.
나머지는 Playwright 가 필요합니다.

품질 기준과 라운드별 점수는 [`docs/QUALITY.md`](docs/QUALITY.md) 에 있습니다.
'좋은 게임, 아름다운 게임'을 감이 아니라 채점 가능한 항목으로 옮겨 두고,
측정 하네스로 숫자를 뽑아 가며 라운드를 돌렸습니다.

최근 실측:

| 항목 | 값 |
|---|---|
| 프레임 (파편 400개 상태) | 평균 **60.0fps**, 최악 프레임 22ms |
| 입력 반영 | 같은 프레임 (0.6ms) |
| DAS / ARR | 실측 157ms / 39ms (설정 150 / 40) |
| 난이도 곡선 | 단조 감소, 최소 비율 0.80 |
| 밤의 시각 색 거리 | 이웃 간 최소 78, 처음과 끝 213 |
| 레이아웃 | 240×400 ~ 3000×1400 무결 |

## 접근성 · 호환

- 최신 Chrome / Safari / Firefox / Edge
- `devicePixelRatio` 대응(최대 2배로 제한), 창 크기와 화면 회전에 반응
- `prefers-reduced-motion` 을 존중해 배경 연출 강도를 낮춤
- 오디오는 기본 켜짐이며 <kbd>M</kbd> 으로 끌 수 있고, 소리 없이도 모든 피드백이 전달됨
- **색 말고도 단서** — 조각마다 다른 '결'이 새겨져 있음
- **키보드 포커스**가 눈에 보이며(`:focus-visible`), 마우스로 누를 때는 뜨지 않음
- **스크린리더** — 줄 삭제·레벨업·종료를 `role="status"` 로 알리고,
  품은 알과 다음 알의 이름을 읽어 줌
- 사파리 프라이빗 모드처럼 **저장소가 막힌 환경**에서도 그대로 동작
  (기록만 남지 않음), `AudioContext` 가 없어도 마찬가지
