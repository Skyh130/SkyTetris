# 품질 기준 — 유리알의 밤

> "좋은 게임, 아름다운 게임이 나왔으면 좋겠다"는 요구를 채점 가능한 형태로 옮긴 문서.
> **목표: 총점 100점 만점에 95점.** 도달할 때까지 라운드를 돌린다.

채점은 두 종류를 섞는다.

- **측정 항목(M)** — 스크립트가 숫자를 뽑는다. 감으로 매기지 않는다. (`tests/perf.js`, `tests/acceptance.js`, `tests/engine.test.js`)
- **판단 항목(J)** — 스크린샷과 코드를 직접 보고 매긴다. 근거를 반드시 한 줄로 남긴다.

**적대적 테스트에서 찾은 진짜 버그** — 사파리 프라이빗 모드처럼 `localStorage`
접근 자체가 막힌 환경에서 게임이 **아예 부팅되지 않았다.** `audio.js` 가 스크립트
로드 시점에 저장값을 읽다가 `SecurityError` 를 맞고 전체가 죽었다.
읽기·쓰기를 감싸는 `Store` 를 두어, 기록만 남지 않고 게임은 그대로 돌아가게 했다.

**언어 감수** — 세계관은 순우리말 서정체인데 UI 에 외래어가 섞여 목소리가 갈렸다.
