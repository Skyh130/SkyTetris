## 1. 한 줄 요약

**짙어가는 가을 밤하늘을 배경으로, 유리알처럼 맑고 투명한 블록을 쌓는 웹 테트리스.**

## 2. 배경과 문제 정의

테트리스는 규칙이 이미 완성된 장르라 "무엇을 만들 것인가"보다 **"어떤 감각으로 만들 것인가"** 가 제품의 정체성을 결정한다.
이 프로젝트의 차별점은 난이도 설계나 신규 규칙이 아니라 **분위기의 일관성**이다.
따라서 아래 두 가지를 제품의 축으로 삼는다.

1. **블록이 진짜로 투명해 보일 것** — 단색 사각형에 알파값만 낮춘 것이 아니라, 뒤 배경이 실제로 비쳐 보이고 굴절·반사·발광이 있는 유리알.
2. **세계관이 장식이 아니라 시스템일 것** — 세계관 텍스트를 곁들이는 데 그치지 않고, **레벨 진행 = 밤이 깊어지는 시간의 흐름**으로 게임 시스템과 직결시킨다.

## 3. 세계관 (Worldview)

> **가을이 다 저문 어느 밤, 하늘에서 유리알이 떨어진다.**
>
> 그것들은 계절이 남기고 간 조각이다. 첫서리가 앉은 자리, 물에 비친 보름달, 떨어지다 굳어버린 단풍잎.
> 조각들은 바닥에 닿으면 그대로 굳어 하늘을 가린다.
> 가로로 한 줄을 온전히 메우면 조각들은 다시 별빛으로 부서져 흩어지고, 그만큼 하늘이 열린다.
>
> 조각을 오래 다룰수록 밤은 깊어진다. 해거름에서 초저녁으로, 자정으로, 서리 내린 새벽으로.
> 밤이 깊을수록 유리알은 더 빨리 떨어지고, 대신 하늘은 더 맑아진다.

### 3.1 일곱 조각의 이름

| 조각 | 이름 | 색 | 유래 |
|---|---|---|---|
| I | 서리결 | 서리 청록 | 첫서리가 길게 내려앉은 자리. 네 줄을 한 번에 거둔다. |
| O | 달빛알 | 달빛 금 | 보름달이 물에 비쳐 그대로 굳은 알. 어느 쪽으로 돌려도 같은 얼굴. |
| T | 자수정 | 자수정 보라 | 밤이 가장 깊을 때만 캐낼 수 있다. 좁은 틈으로 비틀어 들어간다. |
| S | 이끼결 | 이끼 초록 | 돌 그늘에서 자란 초록. 언제나 비스듬히만 눕는다. |
| Z | 단풍잎 | 단풍 진홍 | 떨어지다 말고 굳어버린 잎. 이끼결과는 서로 등을 돌린 사이. |
| J | 쪽빛 | 쪽빛 남색 | 해가 완전히 진 직후, 하늘에서 가장 짙어지는 자리의 색. |
| L | 감빛 | 감빛 주황 | 서리 맞은 감이 끝까지 품고 있던 온기. |

### 3.2 밤의 다섯 시각 (레벨 ↔ 배경 연동)

| 시각 | 도달 레벨 | 하늘 | 별 | 달 |
|---|---|---|---|---|
| 해거름 | 1 | 보랏빛 위 서쪽의 붉은 잔광 | 거의 없음 | 지평선 근처, 흐릿 |
| 초저녁 | 4 | 남보라로 가라앉음 | 첫 별이 돋음 | 낮게 떠오름 |
| 깊은 밤 | 8 | 짙은 감청 | 촘촘해짐 | 중천 |
| 자정 | 12 | 거의 검정에 가까운 남색 | 가장 밝고 많음 | 높이, 가장 선명 |
| 서리 새벽 | 16 | 푸른 기가 도는 검정 | 차갑게 반짝임 | 기울어 내려감 |

- 레벨 사이 구간은 두 시각의 색을 **선형 보간**해 이어 붙인다. 레벨업 순간에 배경이 툭 끊기지 않는다.
- 즉 **플레이어는 자기가 얼마나 오래 버텼는지를 점수판이 아니라 하늘을 보고 안다.**

## 4. 목표 / 비목표

### 4.1 목표
- G1. 표준 테트리스(가이드라인 준수)로서 **조작감에 불만이 없을 것** — SRS 월킥, 7-bag, 홀드, 고스트, 락 딜레이, DAS/ARR.
- G2. 유리알 렌더링과 밤하늘 배경이 **한 화면 안에서 하나의 장면으로 읽힐 것**.
- G3. **의존성 0, 빌드 0** — `index.html`을 열면 바로 실행되고, GitHub Pages에 그대로 배포된다.
- G4. 데스크톱 키보드 / 모바일 터치 **양쪽에서 플레이 가능**할 것.
- G5. 60fps 유지 (일반 노트북 및 최근 모바일 기준).

### 4.2 비목표 (이번 버전에서 하지 않는 것)
- 온라인 대전 / 리더보드 서버 / 계정
- 외부 이미지·폰트·오디오 에셋 (전부 코드로 생성)
- 프레임워크·번들러 도입
- 광고, 결제, 애널리틱스

## 5. 사용자와 사용 맥락

- **주 사용자**: 잠깐(3~10분) 집중할 거리를 찾는 일반 사용자. 테트리스 규칙은 이미 안다.
- **맥락**: 브라우저 탭 하나. 소리를 켜지 않을 수도 있으므로 **오디오 없이도 모든 피드백이 전달**되어야 한다.
- **핵심 가치**: "게임을 잘하는 것"보다 "보고 있기 좋은 것". 지고 나서도 배경을 한 번 더 보게 만든다.

### FR-3. 조작
| 동작 | 키보드 | 터치 |
|---|---|---|
| 좌 / 우 이동 | ← → | 좌우 스와이프 · 화면 버튼 |
| 소프트 드롭 | ↓ | 아래 스와이프 · 화면 버튼 |
| 하드 드롭 | Space | 아래로 빠르게 플릭 · 화면 버튼 |
| 시계 회전 | ↑ 또는 X | 화면 탭 · 화면 버튼 |
| 반시계 회전 | Z 또는 Ctrl | 화면 버튼 |
| 홀드 | C 또는 Shift | 화면 버튼 |
| 일시정지 | P 또는 Esc | 화면 버튼 |
| 다시 시작 | R | 화면 버튼 |
| 음소거 | M | 화면 버튼 |

- FR-3.1 좌우는 **DAS 150ms / ARR 40ms**로 자동 반복.
- FR-3.2 게임 키(방향키·스페이스)는 페이지 스크롤을 막는다.
- FR-3.3 조작 키 안내가 화면에 상시 노출된다.

### FR-4. 유리알 렌더링 (제품 정체성 · 최우선)
| ID | 요구사항 |
|---|---|
| FR-4.1 | **캔버스 2겹 구조** — 뒤: 밤하늘 배경 캔버스(전체 화면), 앞: **배경이 투명한** 게임 캔버스. 블록 너머로 실제 하늘이 비쳐 보여야 한다. |

### FR-7. 오디오 (선택적)
- FR-7.1 Web Audio API로 **합성**한 소리만 사용 (외부 파일 없음).
- FR-7.2 착지 = 낮은 유리 두드림 / 줄 삭제 = 유리 차임 아르페지오 / 레벨업 = 상승음 / 게임오버 = 하강음.

- FR-7.4 브라우저 자동재생 정책 대응 — 첫 사용자 입력에서 AudioContext를 연다.

## 8. 기술 설계

### 8.1 스택
- HTML + CSS + **바닐라 JavaScript (ES2020)**, Canvas 2D. 빌드·의존성 없음.
- ES module을 쓰지 않고 클래식 `<script>` 순차 로드 → `file://` 더블클릭 실행 보장(NFR-6).

### 8.2 파일 구조
```
index.html          레이아웃 · 캔버스 · 오버레이 · 스크립트 로드
css/style.css       유리 패널 UI, 반응형, 오버레이
js/config.js        상수, 조각 정의, SRS 킥 테이블, 밤의 다섯 시각
js/utils.js         보간 · 색 · roundRect · DPR 캔버스
js/audio.js         Web Audio 합성 효과음
js/sky.js           밤하늘 배경 (하늘 · 별 · 달 · 낙엽 · 유성 · 안개)
js/particles.js     유리 파편 / 별빛 파티클
js/glass.js         유리알 한 칸을 그리는 렌더러 (제품 정체성의 핵심)
js/engine.js        순수 게임 로직 (보드 · 조각 · 충돌 · 회전 · 점수)
js/game.js          게임 루프 · 상태 기계 · 연출 트리거
js/input.js         키보드 · 터치 · 화면 버튼
js/main.js          부팅 · DOM 연결
docs/PRD.md         이 문서
README.md           실행 방법 · 조작법
```

### 8.3 설계 원칙
- `engine.js`는 **DOM과 Canvas를 모르는 순수 로직**으로 유지한다 → 규칙을 단독으로 테스트할 수 있다.
- 렌더링은 상태를 바꾸지 않는다. 게임 상태 → 화면은 단방향.
- 배경(`sky`)과 게임(`game`)은 서로를 직접 호출하지 않고, `game`이 `sky.setLevel()`로만 신호를 준다.

### 8.4 게임 상태 기계
```
READY ──시작──> PLAYING ──일시정지──> PAUSED ──재개──> PLAYING
                   │                                     │
                   ├──줄 삭제──> CLEARING ────────────────┘
                   └──스폰 실패──> GAMEOVER ──R──> READY
```
